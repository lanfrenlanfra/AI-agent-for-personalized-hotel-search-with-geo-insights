# Сертификаты

`russian_trusted_root_ca.pem` — корневой сертификат Минцифры. Он нужен только для GigaChat:
цепочка сертификатов API Сбера подписана им, и без него запросы падают с `certificate verify failed`.

Dockerfile скачивает его сам при сборке. Если скачать не получилось (нет сети при сборке),
скачайте файл вручную с https://www.gosuslugi.ru/crt (корневой сертификат, формат для Linux, PEM)
и положите сюда под именем `russian_trusted_root_ca.pem`, затем пересоберите: `docker compose up --build`.

Сертификат используется только для запросов к GigaChat, а не для всей системы.
